AI has made software almost free to create. It has not made it trustworthy. Next-Gen
Factory works with the AI coding tool you already use (Claude Code, Codex, Gemini CLI or
OpenCode) and makes sure what it builds is what you asked for, and that it works, before
anyone calls it done. Every build leaves proof. Every mistake it catches becomes a check
for every builder after you.

We are building it in the open, in Africa, toward one million proven builds by African
builders. [Read why.](MOVEMENT.md)

## Start inside your AI

No commands needed. In Claude Code:

```
/plugin install factory --marketplace next-generation-collective/factory
```

Then ask for what you want in plain words. Cursor, Codex, Gemini CLI and VS Code:
[one line each](docs/USE-IN-YOUR-AI.md).

## Or in a terminal

In any project folder:

```bash
npx @next-generation-collective/factory
```

In about a second it shows what your project can prove: credentials in the code, tests that
check nothing, no tests at all. No account, no questions, and nothing is written to your
project. If it finds a problem, it offers to fix it.

Then start your tasks with it:

```bash
npx @next-generation-collective/factory "add real-time fraud detection to the payments API"
```

Think big. The factory plans the hard parts with you, then proves every one.

- "let doctors dictate notes in any language and get a structured patient record"
- "build a live satellite map of flood risk for every city on the continent"
- "add end-to-end encryption to the chat app"

## What happens

1. **It plans from your code.** What will change, the situations people forget (no
   connection, tapping twice, a small screen), and how each part will be proven.
2. **You approve.** You read only what matters, and press `y`.
3. **Your AI builds it.**
4. **The factory checks it.** It runs your tests and build. Failures go back to the builder.
5. **It uses the app** in a real browser, the way a person would, with a screenshot for every
   check. (In a terminal job for now; inside your AI, this step comes next.)
6. **A second AI reviews it,** in a separate session that never saw how the first one thought.
7. **You get the proof,** and you decide whether to keep the change.

## Why not just use Claude Code?

You should. The factory runs on it. Claude does the work; the factory makes sure the work
is right, proves it, and remembers every mistake so nobody makes it twice.
