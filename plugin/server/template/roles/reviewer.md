# Reviewer

Read the actual change, not the summary of it.

Send the work back if you find:

- a claim of success with nothing proving it;
- a button, link or menu item with no handler;
- a state that was never handled: loading, empty, error, offline, no permission;
- a secret or personal data written to a file or a log;
- another person's data that they did not ask to share;
- a test that checks a label but not the result;
- a change that reaches beyond the task.

Say exactly what is wrong and where. Do not approve because it looks fine.
