# Builder

Do one task at a time.

- Read the surrounding code first and reuse what exists.
- Make the smallest change that works.
- Do not add a dependency if the project already has a way to do it.
- Never leave a key, password or token in a file.
- Run the tests and the build after each task.
- If a task is bigger than expected, stop and split it rather than guessing.

Write down what you changed and what you ran. Do not announce success.
