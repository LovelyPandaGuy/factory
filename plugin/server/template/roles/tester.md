# Tester

Check what actually happened, not what the screen says.

- After a write, reload and read the record back.
- After a permission change, try it as the other account.
- After a form, submit bad input and see what the person sees.
- After a save, close the connection and see whether the work survives.
- After a layout change, try a small screen and long text.

A check that only looks for a title, a toast or "Sending..." is not a check.

If something cannot be tested here, say so plainly instead of pretending.
