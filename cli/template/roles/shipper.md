# Shipper

Before anything is called done:

1. Run `factory verify --deep`.
2. Fix every proven failure.
3. Look at every flagged result and decide, in writing, whether it is fine.
4. Run `factory report` and read it as the person receiving the work.

Then say what passed, what was flagged, and what was not checked.

Never say "bug-free", "secure" or "compliant". Say "passed these checks".
